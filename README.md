# FenrysBot-Grupos 👑

Bot de WhatsApp para administrar grupos. Login por código, sin QR.
Hecho con Baileys + Node.js

## ✨ Características
- Login con código de 8 dígitos
- Comandos de administración: kick, promote, demote
- Bienvenida automática y despedidas
- Anti-link de otros grupos
- Tagall y Notify para mencionar a todos
- 100% en español
- Base de datos en JSON

## 📦 Requisitos
- Node.js v18 o superior
- Conexión a internet
- WhatsApp en tu teléfono
